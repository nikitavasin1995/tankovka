# 🍺 Natankováno

*Natankováno — по-чешски «заправлено» (и немного «навеселе»).* Раньше проект назывался Tankovka.

Карта пивных в Чехии, где наливают **танковое** пиво (tankové pivo), и отметки
«я тут пью» для друзей.

- Сайт: статические файлы, без сборки — `index.html`, `styles.css`, `app.js`, `data/pubs.js`.
- Сервер: [Supabase](https://supabase.com) — вход по email, профили, друзья, отметки и счётчик пива.
  Схема базы и правила доступа — в [`supabase/schema.sql`](supabase/schema.sql),
  инструкция по настройке — в [`SETUP.md`](SETUP.md).
- `config.js` содержит только адрес проекта и **публичный** ключ (`sb_publishable_…`) —
  так и задумано. Секретные ключи и пароль базы сюда не добавлять.

## Приватность

- Местоположение — только по отметке в пивной, без слежки по GPS.
- Отметку видят только друзья и не дольше 8 часов; в профиле можно выбрать «Никому».
- Только 18+.
